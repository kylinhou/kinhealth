📌 核心开发工作流规约 (OpenSpec + Prototype First)

  • ❶ 前置 Demo 优先：任何新功能或核心交互变动，必须先在 design/prototypes/ 编写并验证高保真 HTML 交互原型。
  • ❷ OpenSpec 规范驱动：通过 openspec CLI 管理能力（Spec）、架构设计（Design）与任务清单（Tasks）。
  • ❸ Android 现代技术栈：Kotlin 2.0+ · Jetpack Compose · Material 3 · Room SQLite 离线优先 · MVI 全局成员上下文联动。
